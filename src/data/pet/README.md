# 页面宠物：皮蛋（Pidan）

全站公开页面的动态陪伴小猫组件（`/admin/*` 管理后台不加载）。

## 架构说明

- **组件入口**：`src/components/ReadingPet.astro`（通过 `Footer.astro` 全站挂载，配合 `transition:persist="pidan-pet"` 跨页面保持状态）
- **配置与台词**：`src/data/pet/pidan.ts`
- **真猫卡片素材**：`public/image/pet/cards/pidan-*.webp`（由 `node scripts/generate-pet-cards.mjs` 从原始照片裁剪并压缩生成）
- **双形态设计**：
  1. **Q 版皮蛋（默认动态模式）**：纯矢量骨骼分层绘制（海豹重点色挖煤脸、冰蓝宝石眼、飞机腮帮毛、纯白大围脖、四只黑手套、蓬松黑棕大尾巴 + 可开关小鱼甜甜圈皮肤），支持自主散步、眼神跟随鼠标、打盹呼噜、撸猫连击、投喂小鱼干、拎后颈皮拖拽定位、快速滚动飞机耳反应与文章阅读进度陪读。
  2. **真实皮蛋（拍立得萌照卡模式）**：固定于左下角的拍立得卡片与高清灯箱，支持翻页、随机吸猫与一键切回 Q 版动态，避免生硬移动原始照片。
